AIAI 设置

0 套配置

这些设置存在这台电脑的浏览器里，不会上传到任何服务器；Key 只在调用时直接发给服务商。 同一个浏览器里的各个工具（刷题、单片机、考试……）共用这一份配置。

模型配置

一套 = 一家服务商的一个模型。同一个 Key 可以配多套：便宜的跑批量出题，带视觉的专门读照片。

新增一套

能力标签

不勾「记住」时 Key 只在这个标签页里活着：关掉页面就得重填。勾了就存在本机浏览器，下次打开直接能用。

按能力设默认

工具没单独指定时，就按这里找模型。

按工具指定（可选）

留空就跟随上面的默认。需要读图的工具（比如刷题导入照片）要选勾了「图片识别」的那套。

导入 / 导出

换电脑或者给同事复制配置用。导出的 JSON 里没有 Key（Key 只在你自己的浏览器里，本来就不该跟着文件走）， 导入后要把每套的 Key 补上。
