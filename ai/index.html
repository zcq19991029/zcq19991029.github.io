AIAI 设置

0 个平台 · 0 个模型

这些设置存在这台电脑的浏览器里，不会上传到任何服务器；Key 只在调用时直接发给服务商。 同一个浏览器里的各个工具（刷题、单片机、考试……）共用这一份配置。
一个平台 = 一个 Key + 一个接口地址；同一个平台下面可以挂任意多个模型（便宜的跑批量、带视觉的读照片），Key 只填一次。

平台与模型

先加平台（服务商 + 接口地址 + Key），再在平台下面加模型。 加模型时先选平台，再「读取模型」把它真有的模型列出来 —— 只加这个平台能用的，别硬塞。

新增平台

一个平台只填一次 Key，它下面的所有模型共用。不勾「记住」时 Key 只在这个标签页里活着。

新增模型

能力标签（这个模型能干什么，全列在这儿；按模型名预勾，不对就自己改）
思考程度

思考程度决定「想多想久」：快速少想回得快，深度多想更准，均衡跟随模型默认。 会落到真实请求参数里（reasoning_effort / thinking / temperature，按各家认的字段传）。

按能力设默认

工具没单独指定时，就按这里找模型。先选平台，再选模型 —— 模型下拉里只有这个平台里勾了这项能力的，选不出「用 deepseek 生成视频」这种错配。

按工具指定（可选） 已按推荐：0/7

留空就跟随左边的默认。需要读图的工具（比如刷题导入照片）要选勾了「图片识别」的模型。 每行下面写着这个工具的推荐：能力够用的那一套；当前选的不是它时，右边会多一个「按推荐」。

每个工具用哪套（总览）

一屏看清每个工具实际调哪个平台的哪个模型。这里只是展示，要改还是用上面的下拉。

导入 / 导出

换电脑或者给同事复制配置用。导出的 JSON 里有平台和模型，没有 Key（Key 只在你自己浏览器里）。 导入后每个平台「编辑」补一次 Key 就行，不用每个模型都补。

AI 注册渠道与工具建议

工具里的 AI 功能要有一把自己的 Key 才能用。下面几个平台注册门槛低，按顺序挑一个， 把 Key 配到上面的「平台与模型」里（硅基流动一个 Key 就有文本 / 读图 / 文生图 / 文生视频 / 语音，最省事）。

提示：这些是第三方平台，注册和使用要遵守它们自己的规则；用不用、用哪个都不影响华夏工具的正常使用。
