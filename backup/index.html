全站备份

一键导出 / 恢复整个华夏工具在本机的全部本地数据（localStorage + 音乐库 IndexedDB）。换电脑、换浏览器或担心数据丢失时用。

导出备份

把下面列出的所有工具的本地数据打包成一个 JSON 文件下载到本机。建议定期导出保存。

导入备份

选一个之前导出的备份 JSON 文件，解析后写回本机。导入会覆盖当前本地数据，请先确认。

尚未选择文件

导入范围与导出一致：localStorage 按 key 逐条覆盖写入（不清除备份里没有的 key）；音乐库先清空再整份恢复。备份含登录会话（paike-session），导入后可能需要重新登录。
