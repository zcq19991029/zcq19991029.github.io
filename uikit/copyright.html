这套东西怎么用

  • 源码：每个组件都给出可以直接复制到别的项目里跑的 HTML / CSS / JS，不依赖本站的构建流程。
  • 复刻提示词：一段写给 AI 的完整需求，粘过去就能让它把这个组件重做一遍 —— 比只给代码更适合「我要改成我们自己的风格」。
  • 预览：iframe 里跑的是真组件，不是截图。可以点、可以拖、可以切深浅。
  • API 参考：属性、方法、事件、CSS 变量，够你判断「能不能直接套用」。

欢迎抄、欢迎改。唯一的要求：抄走的时候把出处留着，别把别人的东西说成自己原创。
