# 华夏工具

机电教研室的教学与教务工具，一个网站、一个账号：

**https://zcq19991029.github.io/**

| 工具 | 给谁用 | 做什么 |
|---|---|---|
| 接线仿真 | 老师、学生 | 《电气控制技术实训》项目二 2.1～2.6 和电工中级扩展题：在线连线、检查、仿真试车；排位计时上排行榜 |
| 排课 | 老师 | 教研室每周一晚修排课：轮换、月课表、按学院原表导出 Excel 和 PNG |
| 小组加分 | 老师 | 小组制课堂记分：全组奖励、个人评价、考勤、平时赋分与期末目标 |

- 顶部选项卡切换工具，右上角是账号。老师能用全部工具；学生用课堂码开通，只能用接线仿真。
- 登录方式：账号名或邮箱 + 密码，或 GitHub。新账号要填邀请码开通。
- 不登录也能做接线练习，排位要登录。
